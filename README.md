# grandma's search history

a tiny browser game where you get temporary access to grandma's computer and inspect the damage.

## what it is

- click searches in grandma's history to see what popped up
- mark searches as harmless, concerning, or legendary
- add your own custom grandma searches
- custom searches auto-generate grandma-style results

## run it

just open `index.html` in a browser. no build, no deps, no nonsense.

## seed chaos includes

- letter size battles
- hashtag crime investigations
- chin-based videocall incidents
- mailman reconnaissance
- roblox gang infiltration
- the brayden gt5 revenge arc
- becoming 40 years old
